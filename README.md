# Mandible: War Beneath the Grass

A real-time strategy game at ant scale. Queens ascend through five levels, unlocking new castes and heroes that level up to 10; wild beetles, spiders and wasps guard the richest food with their own special attacks. Choose your colony: **black garden ants** (Lasius niger: huge numbers, strong trails, honeydew farmers, formic acid) or **red fire ants** (Solenopsis invicta: venom stings, mound fury, protein-hungry predators). Workers forage on their own along real pheromone trails; each kind of food does something different (sugar speeds workers, fruit heals, insect protein makes the queen lay faster, seeds are dense but heavy). Fallen ants become food, and you win by killing the enemy queen. The in-game **Field Guide** explains every caste, bug and food, how real ants find food, and what a colony needs, with live 3D portraits.

Built with Godot 4.7 (.NET / C#). Every model, texture, sound and music track is generated by the project itself. The only external assets are the Cinzel and Inter fonts (SIL Open Font License, in `assets/fonts`).

Double-click **`Play Mandible.bat`**, or run:

## Multiplayer (LAN and internet, Windows / macOS / Android / iOS)

Main menu, then **Multiplayer**. One player hosts, the other joins. The host picks a colony (black garden ants or red fire ants); the guest leads the other.

- **Same Wi-Fi or LAN:** choose *Host on this network*. The game appears automatically in the other player's *Games on your network* list.
- **Over the internet:** choose *Host over the internet*. Mandible asks the router to open UDP port 47010 (UPnP) and shows your internet address to send to your friend, who types it into *Join*. If the router refuses, forward UDP 47010 to the host PC manually.
- Phones on mobile data usually cannot *host* (carrier NAT) but can join a PC host.

The game uses deterministic lockstep: both machines run the identical simulation and only orders cross the network (a few hundred bytes a second), so it stays light on mobile data. Input delay adapts to the measured ping. Checksums are compared every second; a mismatch is reported in the HUD.

Touch: tap to select, drag to box-select, tap the ground to order the selection, long-press for attack-move, double-tap empty ground to deselect, two fingers to pan / pinch-zoom / twist-rotate.

Graphics: Main menu, then *Graphics* cycles High / Medium / Low. Phones and tablets start on Low.

## Layout

| Path | What |
|---|---|
| `src/Sim` | Simulation: ants, foraging, pheromones, combat, colonies, crumb showers |
| `src/World` | Procedural, mirrored backyard: soil, leaves, twigs, rocks, grass, food, nests |
| `src/Render` | Ant meshes and the GPU-instanced renderer, shaders, particles |
| `src/Game` | Session, camera, player input, fog of war, AI |
| `src/UI` | HUD, minimap, theme |
| `src/Audio` | Positional audio, swarm layer, adaptive music |
| `tools/gen_audio.py` | Synthesises every sound and music track into `assets/audio` |

## Testing tools

```bash
powershell -File tools/capture.ps1 captures
```

The command above runs a scripted screenshot tour plus an input self-test (box select, orders, hotkeys).

```bash
"D:\Tools\Godot\Godot_v4.7.2-stable_mono_win64\Godot_v4.7.2-stable_mono_win64_console.exe" --headless --path . -- --simtest=1800,Normal,Hard
```

The command above plays a full AI-vs-AI match without graphics and prints economy, army and frame-time stats every minute.

```bash
godot --headless --path . -- --nettest=host,600
godot --headless --path . -- --nettest=join:127.0.0.1,600
```

The two commands above run a full networked AI-vs-AI match between two processes and report checksum matches and desyncs.

\\ash
powershell -File tools/balance.ps1 -Diff Normal -Games 8

The command above plays black vs red on 8 different maps at once and prints who won each.
